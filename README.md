# PasswordGenerator
## 📖 درباره پروژه (Overview)

برنامه **PasswordGenerator** یک ابزار کاربردی و مستقل برای ویندوز است که به شما امکان می‌دهد به‌راحتی و تنها با چند کلیک، گذرواژه‌های بسیار امن، غیرقابل پیش‌بینی و متناسب با نیاز خود تولید کنید. این نرم‌افزار نیازی به نصب ندارد و بلافاصله پس از اجرا آماده به کار است.

---

## ✨ ویژگی‌های اصلی (Key Features)

- 📏 **تنظیم طول پسورد:** قابلیت تعیین طول گذرواژه به اندازه دلخواه.
- ⚡ **تولید آنی و سریع:** ساخت پسورد قوی تنها با فشردن یک دکمه.
- 📋 **کپی آسان (One-Click Copy):** امکان کپی‌کردن مستقیم پسورد تولیدشده در کلیپ‌بورد.
- 🚀 **بدون نیاز به نصب (Portable):** اجرا به‌صورت مستقیم روی تمامی سیستم‌عامل‌های ویندوز.
- 🔒 **ارتقای امنیت:** تولید کاراکترهای تصادفی پیچیده جهت جلوگیری از حملات Brute-Force.

---

## 🚀 راهنمای استفاده (Usage Guide)

استفاده از برنامه بسیار ساده است؛ کافی است مراحل زیر را دنبال کنید:

1. **اجرای برنامه:** فایل اجراپذیر `PasswordGenerator.exe` را باز کنید.
2. **انتخاب طول پسورد:** با استفاده از بخش مربوطه، طول مدنظر برای پسورد را مشخص کنید.
3. **ساخت پسورد:** روی دکمه **«ساخت پسورد»** کلیک کنید.
4. **کپی‌کردن:** دکمه **«کپی»** را بزنید تا پسورد در کلیپ‌بورد شما ذخیره شود و بتوانید آن را در محل دلخواه استفاده کنید.

---

## 🛠️ پیش‌نیازها و نصب (Requirements & Installation)

- **سیستم‌عامل:** Windows 7 / 8 / 10 / 11
- **نصب:** این نرم‌افزار به‌صورت **Standalone / Portable** آماده شده است و نیازی به مراحل نصب یا نرم‌افزار پیش‌نیاز ندارد.
